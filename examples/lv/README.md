# LV Examples

This folder contains runnable examples for **left ventricle (LV)** workflows.
The unloaded and loaded geometry should be in the form of .inp and .pt;
Inverse identification results are stored in examples/lv/inverse_mat_ex_vivo_NN

Planned examples:
1. LV forward inflation (given material params + unloaded geometry → pressurized geometry)
2. LV inverse identification (given unloaded/pressurized observations → material params)


Start here:
- `LV_FEA_QN_forward_inflation.py`
- `LV_FEA_inverse_mat_ex_vivo_NN.py`
